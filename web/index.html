Analizador

  

    
El compilador revisa el programa en tres fases, una después de otra. Si una fase encuentra errores, las siguientes no se ejecutan. Si todo está bien, el programa se ejecuta.

    

      
FaseQué comprueba

      
        
1. Análisis léxicoQue cada palabra, número, texto y símbolo pertenezca al lenguaje. Separa el código en tokens (pestaña Reporte).

        
2. Análisis sintácticoQue los tokens estén en el orden correcto: declaraciones, asignaciones, Mensaje, Captura y Si / Sino / FinSi. Construye el árbol sintáctico (pestaña Árbol Sintáctico).

        
3. Análisis semánticoQue el programa tenga sentido: variables declaradas, tipos compatibles, condiciones Verdadero/Falso. Llena la Tabla de Símbolos.

        
4. EjecuciónCorre las instrucciones y muestra los resultados en Salida del Programa. Pide los datos de Captura.
